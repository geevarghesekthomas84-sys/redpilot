What it does

◇ Autonomous agent

The AI plans which modules to run, chains them, and writes the assessment — scope-gated, no raw commands.

◇ Recon toolkit

One pipeline wrapping subfinder, httpx, nuclei, katana, dnsx, ffuf and more.

◇ Staged pipeline

Deterministic discovery → validation → remediation → report, with strict stage hand-offs.

◇ API + dashboard

Headless REST + WebSocket, a built-in web console, and Prometheus metrics.

◇ MCP + plugins

Drive RedPilot from Claude Desktop as native tools; add scanners via the plugin SDK.

◇ Multi-engagement RBAC

Isolated workspaces, viewer/operator/lead roles, and signed engagement authorizations.

Safety first

◇ Scope & authorization

Out-of-scope targets refused; overly-broad scans rejected; active runs need a signed authorization.

◇ Safe execution

No shell execution of untrusted text; AI/target output sanitized; secrets redacted from logs.

◇ Audited & observable

Every active action is audit-logged; rate-limited API; Trivy + pip-audit + SBOM in CI.

RedPilot is authorized-testing-only tooling. You are responsible for having written permission for every target.
